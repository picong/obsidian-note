# 首页使用说明

## 📋 已创建的文件

1. **首页文件**: `03_Maps/首页.md`
2. **CSS 样式**: `.obsidian/snippets/homepage.css`
3. **完整索引**: `03_Maps/首页索引.md`（详细版本）

## 🎨 启用样式

### 步骤 1: 启用 CSS 片段

1. 打开 Obsidian 设置（快捷键：`Ctrl/Cmd + ,`）
2. 进入 **外观 (Appearance)** 设置
3. 滚动到 **CSS 代码片段 (CSS snippets)** 部分
4. 点击刷新按钮（🔄）
5. 找到 `homepage` 并启用它

### 步骤 2: 设置为启动页

1. 打开 Obsidian 设置
2. 进入 **核心插件 (Core plugins)**
3. 启用 **主页 (Homepage)** 插件
4. 在主页插件设置中，设置启动文件为：`首页.md`（如果在根目录）

### 步骤 3: 启用 Banner 插件（可选）

如果你想使用横幅图片：
1. 在社区插件中搜索并安装 **Banner** 插件
2. 启用插件
3. Banner 会自动读取首页 frontmatter 中的 `banner` 配置

## 🖼️ 自定义图片

### 方法 1: 使用在线图片（当前方式）

首页当前使用 Unsplash 的图片：
```markdown
![banner](https://images.unsplash.com/photo-1519681393784-d120267933ba?w=1920&h=400&fit=crop)
```

你可以替换为其他 Unsplash 图片链接，或任何在线图片 URL。

### 方法 2: 使用本地图片（推荐）

1. 在知识库根目录创建 `attachments` 文件夹（如果还没有）
2. 将你喜欢的图片放入该文件夹，例如：`attachments/banner.jpg`
3. 修改首页中的图片链接：

```markdown
![banner](attachments/banner.jpg)
```

### 推荐的图片尺寸

- **宽度**: 1920px
- **高度**: 400-600px
- **格式**: JPG, PNG, WebP
- **风格**: 简洁、留白多、色调柔和

### 图片资源推荐

- [Unsplash](https://unsplash.com/) - 免费高质量图片
- [Pexels](https://www.pexels.com/) - 免费图片和视频
- [Pixabay](https://pixabay.com/) - 免费图片

## 📝 自定义内容

### 修改标题

编辑 `03_Maps/首页.md`，修改以下部分：

```markdown
# 知识花园

*构建属于自己的知识体系*
```

### 添加/删除领域卡片

每个领域使用 Callout 语法：

```markdown
> [!note]- 🎯 领域名称
>
> **子主题**
>
> [[笔记1]] · [[笔记2]] · [[笔记3]]
```

- `[!note]-` 中的 `-` 表示默认折叠
- 可以改为 `[!note]+` 表示默认展开
- 可以使用其他 Callout 类型：`tip`, `info`, `warning`, `example` 等

### 修改底部引用

```markdown
*"The best time to plant a tree was 20 years ago. The second best time is now."*
```

替换为你喜欢的名言或座右铭。

## 🔧 进阶自定义

### 修改颜色主题

编辑 `.obsidian/snippets/homepage.css`，修改以下变量：

```css
/* 主色调 */
border-left: 4px solid var(--interactive-accent);

/* 背景色 */
background: var(--background-secondary);

/* 文字颜色 */
color: var(--text-normal);
```

### 调整卡片样式

在 CSS 文件中找到 `.homepage .callout` 部分，可以修改：
- `border-radius`: 圆角大小
- `padding`: 内边距
- `margin`: 外边距
- `box-shadow`: 阴影效果

### 修改图片高度

```css
.homepage img[alt="banner"] {
    height: 300px; /* 修改这个值 */
}
```

## 💡 使用技巧

### 1. 配合 Dataview 插件

可以在首页添加动态内容，例如最近修改的笔记：

```markdown
> [!info]- 📅 最近更新
>
> ```dataview
> TABLE file.mtime as "修改时间"
> FROM ""
> SORT file.mtime DESC
> LIMIT 5
> ```
```

### 2. 添加快捷操作

可以添加常用操作的链接：

```markdown
[[Templates/基础笔记模板|📝 新建笔记]] · [[00_Inbox|📥 收件箱]] · [[首页索引|📖 完整索引]]
```

### 3. 使用 Banner 插件

如果安装了 Banner 插件，可以在 frontmatter 中设置横幅：

```yaml
---
banner: "attachments/banner.jpg"
banner_y: 0.5
---
```
