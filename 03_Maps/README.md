## 🎯 什么是知识地图（MOC）

**Map of Content（MOC）** 是连接和组织笔记的中心枢纽：

- 🗺️ **导航作用**: 帮助快速找到相关笔记
- 🔗 **连接作用**: 建立笔记之间的关系
- 📊 **概览作用**: 展示某个主题的全貌
- 🧭 **引导作用**: 提供学习路径和思路

## 💡 如何创建知识地图

1. **选择主题**: 确定要整理的知识领域
2. **收集笔记**: 找出所有相关的笔记
3. **建立结构**: 按逻辑关系组织笔记
4. **添加说明**: 为每个部分添加简短说明
5. **持续更新**: 随着学习深入不断完善

## 🎨 地图类型

### 按主题分类
- 技术主题地图（如：Kubernetes、Java、分布式系统）
- 概念主题地图（如：设计模式、算法、架构）
- 项目主题地图（如：具体项目的知识整理）

### 按功能分类
- 📖 **索引型**: 列出所有相关笔记
- 🎯 **路径型**: 提供学习路径和顺序
- 🔗 **关系型**: 展示概念之间的关系
- 📊 **概览型**: 提供主题的全局视图
